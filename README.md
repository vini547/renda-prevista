# Predição de Renda com CRISP-DM
Projeto voltado à criação de um modelo de Machine Learning para prever a renda de clientes de um banco. Utilizando a metodologia CRISP-DM, análoga ao método científico, o processo envolve desde a compreensão do negócio e dos dados até a modelagem, avaliação e implantação da solução. O objetivo é gerar previsões precisas de renda a partir de variáveis socioeconômicas e comportamentais, apoiando decisões estratégicas da instituição financeira.
